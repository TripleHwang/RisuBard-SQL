# RisuVault v0.3.2.6 Hotfix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.3.2.6 with atomic full-character selection, non-destructive SQL summary persistence, selective recovery, stable deferred-settings UI, and live RisuRealm compatibility.

**Architecture:** Keep the metadata-first bootstrap, but separate SQL row metadata updates from extension-body replacement. Treat character selection as a targeted transaction that hydrates character body, chat body and a bounded recent message page before changing the selected character; use the pre-SQL backup only for a narrowly detected collapsed body. Normalize live Realm data at the transport boundary and keep deferred-settings feedback inside stable layout bounds.

**Tech Stack:** Svelte 5, TypeScript, Node 24, Express, `node:sqlite`, Vitest, pnpm.

- [ ] **Step 3: Implement bounded repair detection and commit**
