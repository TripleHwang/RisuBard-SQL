# 콘텐츠 분석

- 목적: 긴 채팅의 전체 재전송 문제와 RisuBard의 위키 기반 고정 예산 메모리를 비개발자도 즉시 이해하게 한다.
- 독자: 캐릭터 채팅 사용자와 오픈소스 기여자.
- 형식: GitHub README에서 세로로 이어지는 대형 웹툰 패널 4장.
- 화풍: 단순하고 귀여운 manga 일러스트, 깨끗한 선, 따뜻한 크림색과 하늘색 중심의 제한 팔레트.
- 핵심 대비: 책 더미에 눌린 AI 로봇 대 메모와 위키를 활용하는 여유로운 RisuBard쨩.
- 텍스트: 한국어 대사만 사용하며 각 패널에 지정된 문구 외의 글자는 넣지 않는다.
