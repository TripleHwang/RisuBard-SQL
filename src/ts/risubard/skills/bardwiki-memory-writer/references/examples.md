# 경계 사례

## 지시와 결과

지시: `다음 장면에서 다리를 무너뜨려라.`

적용 원고에 다리가 무너지는 장면이 없으면 기록하지 않는다. 적용 원고에 `굉음과 함께 다리가 끊어졌다.`가 있으면 다리 붕괴를 확정 사건으로 기록한다.

## 지식 경계

원고에 범인이 독자에게만 드러나고 인물 라비안은 보지 못했다면 객관적 사건은 기록하되 라비안의 `knows`로 기록하지 않는다.

## 추론 금지

원고에 `라비안은 대답하지 않았다.`만 있다면 분노, 불신, 결별을 만들지 않는다.

## 상태 변화

이전 기록과 확정 본문이 이동 전후를 모두 뒷받침하면 `북문으로 이동 중 → 북문에 도착`으로 기록한다. 이전 상태가 불명확하면 `before: null`을 사용한다.

## 원고 교정과 세계의 변화

편집으로 `문은 닫혀 있었다`를 `문은 열려 있었다`로 교체했더라도, 확정 원고가 문이 열리는 행동을 묘사하지 않으면 ‘문이 열렸다’는 사건이나 상태 전이를 만들지 않는다. 현재 사실 `문은 열려 있다`만 기록한다. 폐기된 문장은 프로그램이 겹치는 옛 사건 근거를 supersede하는 데만 사용한다.
