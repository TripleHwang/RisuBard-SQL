# RisuBard v0.9.6

이번 버전은 **BardWiki와 함께 사용하는 자동저장과 채팅 가져오기 안정화**에 초점을 맞췄습니다.

## 자동저장 안정화

- 자동저장 간격을 설정해도 계속 `자동저장 대기 중`으로 남고 실제 저장 파일이 생성되지 않던 문제를 수정했습니다.
- 최신 AI 응답의 다음 턴 확정을 기다리던 잘못된 조건을 제거했습니다.
- 이제 채팅 응답 생성과 BardWiki 작업이 모두 끝난 뒤 설정한 턴 간격에 맞춰 자동저장합니다.
  - 자동저장 간격을 `1`로 설정하면 완료된 AI 응답마다 저장합니다.
  - 메시지를 지우거나 별도의 수동 동작으로 자동저장을 깨울 필요가 없습니다.

## 채팅 가져오기와 BardWiki

- 같은 RisuBard 데이터 프로필에서 내보낸 채팅 JSON을 다시 가져오면 원본 BardWiki 작업공간도 새 채팅으로 복제합니다.
  - Markdown 정본, 사건, 변경 이력, 턴 영수증과 휴지통 자료를 함께 보존합니다.
  - 채팅 저장이 성공한 뒤에만 복제한 BardWiki를 확정하며, 저장에 실패하면 가져오기와 임시 Wiki를 함께 되돌립니다.
- 오래된 채팅 파일이나 다른 설치에서 가져온 파일처럼 원본 BardWiki 작업공간을 찾을 수 없는 경우, 메시지에 남아 있던 위키 확정 표식을 초기화합니다.
  - 빈 BardWiki가 이미 완성된 위키처럼 취급되는 상태를 방지합니다.
  - 전체 BardWiki를 다시 만들려면 위키 리부트를 실행할 수 있도록 안내합니다.
- 다른 설치 환경으로 BardWiki까지 옮길 때는 채팅 JSON 대신 BardWiki를 포함하는 전체 백업을 사용해야 합니다.
