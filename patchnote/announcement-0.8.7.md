# 리스바드 v0.8.7 업데이트 — 프리셋·모듈·플러그인 폴더 정리

![프리셋, 모듈, 플러그인이 각각 폴더로 정리되는 모습](../assets/announcement/risubard-v0.8.7-folder-organizer.png)

안녕하세요. 리스바드 **v0.8.7**을 배포했습니다.

이번 버전의 핵심은 **프롬프트 프리셋, 모듈, 플러그인 폴더 정리 기능**입니다.

처음에는 별도의 폴더 관리자 창에서 항목을 넣고 빼는 형태로 만들었는데, 그렇게 하면 정리한 뒤 다시 원래 목록으로 돌아가야 해서 실사용 의미가 적었습니다. 그래서 v0.8.7에서는 폴더 관리자를 따로 띄우지 않고, **평소 사용하는 기본 목록 자체에 폴더 기능을 통합**했습니다.

## 기본 목록에서 바로 정리하고 바로 사용

프롬프트 프리셋, 모듈, 플러그인 화면에서 다음 작업을 바로 할 수 있습니다.

- 폴더 생성, 이름 변경, 삭제
- 전체 항목과 미분류 항목 보기
- 이름 검색과 폴더별 항목 수 확인
- 여러 항목 선택 후 한 번에 폴더 이동
- 드래그 앤 드롭으로 항목 이동
- 폴더와 항목의 표시 순서 변경

폴더로 화면을 좁혀도 기존 기능은 사라지지 않습니다.

- **프롬프트 프리셋:** 선택, 편집, 복제, 내보내기, 삭제
- **모듈:** 활성화, 페르소나 할당, 편집, 삭제
- **플러그인:** 업데이트, 활성화, 권한 초기화, 인자 편집, 삭제

즉, 정리만 하는 보조 창이 아니라 **정리한 상태 그대로 실제 관리와 사용을 이어가는 목록**입니다.

## 폴더를 지워도 내용물은 지워지지 않음

폴더 정보는 프리셋·모듈·플러그인 원본과 분리해서 저장합니다.

따라서 폴더를 삭제해도 안에 있던 항목은 함께 삭제되지 않고 **미분류**로 돌아갑니다. 항목을 다른 폴더로 옮기거나 폴더 순서를 바꿔도 현재 활성 프리셋, 모듈, 플러그인의 실행 상태는 바뀌지 않습니다.

기존 데이터 형식도 그대로 유지하므로 업데이트 후 예전에 쓰던 항목을 다시 가져오거나 재설정할 필요가 없습니다.

## 페르소나별 모듈 활성화

모듈에는 페르소나 할당 기능도 추가했습니다.

모듈 설정에서 사용할 페르소나를 검색해 지정할 수 있고, 현재 활성 페르소나에 할당된 모듈만 기존 전역·채팅·캐릭터 모듈에 추가됩니다. 같은 캐릭터를 사용하더라도 페르소나마다 서로 다른 보조 프롬프트나 규칙을 적용할 수 있습니다.

## 그 밖의 v0.8.7 변경점

- LLM 번역 캐시 검색, 편집, 복사, 개별·전체 삭제, 가져오기와 내보내기
- 여러 창에서 같은 번역 캐시를 수정할 때 최신 값을 보호하는 충돌 감지
- 플러그인 업데이트 시 오래된 브라우저 캐시를 우회하고 실제 설치·저장 완료 확인
- 대용량 로컬 백업 복원의 메모리 사용량과 연결 안정성 개선
- 홈 화면에 현재 리스바드 버전 표시
