# RisuVault 0.3.1

- 시작 시 전체 대화 본문 대신 메타데이터를 먼저 불러와 초기 로딩 부담을 줄였습니다.
- 채팅과 이미지는 필요한 범위만 유지하도록 메모리 사용량을 제한했습니다.
- 저장은 변경된 행 단위로 처리하며, 자동 saver mode가 장시간 사용 중 저장 부담을 조절합니다.
- 서버 지원 `.risum` 가져오기와 저장 폴더 가져오기는 스트리밍 방식으로 대용량 파일을 처리합니다.
- 기존 데이터와의 호환 동작을 유지하고, 생성된 기준 프로필(200 캐릭터, 20,000 메시지, 논리적 20 GiB 자산 카탈로그)로 검증합니다.

기기와 브라우저의 메모리 한계는 서로 다르므로, 모든 WebKit 환경에 대한 고정 메모리 보장을 약속하지는 않습니다. iOS 17+ Safari 및 설치형 PWA는 지원 사양에 포함되지만, 이 릴리스의 실제 iPhone 기기 검증은 아직 완료되지 않았습니다. Android 실기기 검증은 릴리스 후 후속 절차로 진행합니다.
