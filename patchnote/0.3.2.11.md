# RisuVault 0.3.2.11

- 채팅에서 위로 올려 이전 메시지를 불러올 때 가장 오래된 부분에 도달하면 "Retry"만 표시되고 더 이상 불러오지 못하던 문제를 수정했습니다. 메시지 위치 값이 겹치는 채팅에서도 정상적으로 불러옵니다.
- 채팅을 여러 번 전환하면 메시지가 표시되지 않고 첫 메시지만 남던 문제를 수정했습니다. 다른 채팅의 저장이나 자동 저장 등 관계없는 작업이 채팅 불러오기를 중단시키고 있었습니다.
- 플러그인 업데이트가 브라우저 단계에서 차단되어 실패하던 문제를 수정했습니다. 업데이트 확인과 다운로드 요청이 불필요한 사전 요청을 유발하지 않도록 바꿨습니다.
- 플러그인을 업데이트한 뒤 새로고침하면 이전 버전으로 돌아가던 문제를 수정했습니다. 저장이 실제로 이루어지지 않은 채 완료로 표시되고 있었으며, 같은 문제를 겪던 채팅·볼트·위키 편집기의 저장 경로도 함께 수정했습니다.
- 플러그인이 업데이트 주소를 스스로 변경한 경우 설치가 완료되었는데도 실패로 표시되던 문제를 수정했습니다.
- 정규식 스크립트의 플래그 항목에 공백이 들어 있으면 스크립트가 아무런 안내 없이 동작을 멈추던 문제를 수정했습니다. 정규식을 사용할 수 없을 때는 편집기에 오류를 표시하며, 인식할 수 없는 플래그 태그도 함께 안내합니다.
- 정규식 편집기에서 플래그 버튼을 끄면 사용자 지정 태그의 글자가 지워지던 문제를 수정했습니다.
- 플러그인 업데이트 실패 시 어느 단계에서 실패했는지 표시하고, 이전 메시지 불러오기 실패도 기록에 남깁니다.
