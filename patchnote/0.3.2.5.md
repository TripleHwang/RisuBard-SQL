# RisuVault 0.3.2.5

- 첫 화면이 상호작용 가능해진 뒤 SQL 지연 로딩을 시작하도록 조정하고, 지연 초기화 중 기본값·URL 가져오기·사이드바 변경이 반복되거나 안전하지 않게 저장되지 않도록 수정했습니다. 실패 시에는 재시도할 수 있습니다.
- RisuRealm 기본 탐색은 영속 캐시를 먼저 표시한 뒤 최신 결과를 갱신하는 방식(SWR)으로 개선했습니다. 동시에 발생한 요청, 늦게 도착한 응답, 오류와 재시도 상황에서도 현재 화면의 결과가 안정적으로 유지됩니다.
- 채팅 기록을 이전/다음 페이지 버튼 대신 연속적이고 범위가 제한된 기록 창으로 표시합니다. 위아래 스크롤과 재시도로 오래된 메시지를 불러오며, 이전에는 접근하기 어렵거나 잘린 오래된 채팅을 열 수 있도록 수정했습니다.
- 기존 메모리 최적화 기준인 60/40은 그대로 유지됩니다.
