# RisuVault 0.3.2.1

- 최초 실행의 `Migrating Local Save to SQL Database...` 단계에서 SQL 전체 스냅샷을 다시 다운로드하고 모든 채팅을 재구성하던 중복 검증을 제거했습니다.
- 마이그레이션 완료 여부는 가벼운 SQL 부트스트랩 상태와 커밋 리비전으로 검증하며, 백업 선행·단일 트랜잭션·실패 시 레거시 저장 복구 동작은 그대로 유지합니다.
- 대량 마이그레이션 중 반복되는 SQL prepared statement를 커밋 범위에서 재사용해 서버의 SQL 준비 비용을 줄였습니다.
- replace-all 저장 시 플러그인 및 프리셋 테이블을 중복 삭제하던 작업을 정리했습니다.

이 패치는 최초 로컬 저장 데이터를 SQL로 옮기는 시간만 최적화하며, 모듈의 이미지 표시 조건이나 채팅 렌더링 규칙은 변경하지 않습니다.
