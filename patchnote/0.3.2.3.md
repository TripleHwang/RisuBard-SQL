# RisuVault 0.3.2.3

- SQL 전환 상태를 서버 데이터베이스에 기록하고 서버가 기존 저장 파일을 직접 변환하도록 바꿔, 새로고침할 때마다 `Migrating Local Save to SQL Database...`가 반복되던 문제를 수정했습니다.
- 정상 실행 시 캐릭터와 채팅의 목록 정보만 먼저 불러오고 상세 내용과 메시지는 필요한 시점에 읽도록 하여 시작 로딩 비용을 줄였습니다.
- 플러그인 목록의 `+` 업데이트가 완료될 때까지 기다린 뒤 결과를 표시하고, 기존 활성화 상태와 사용자 설정을 보존하도록 수정했습니다.
- 직접 연결한 localhost/LAN 환경에서 256 MiB를 넘는 CharX와 50 MiB를 넘는 내부 에셋도 파일 기반으로 임포트할 수 있습니다. 경로, CRC, 디스크 여유, 압축 해제 안전 검사는 유지됩니다.
- 메시지 페이지의 `다음` 버튼이 다음 페이지의 맨 위로 이동하도록 수정했습니다. `최신` 버튼은 기존처럼 마지막 메시지로 이동합니다.

Cloudflare 터널의 업로드 제한 변경은 이번 버전에 포함하지 않았습니다.
