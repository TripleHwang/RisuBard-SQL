# RisuVault 0.3.2.0

- `Opening SQL Database...` 단계에서 인증과 세션 준비를 병렬화하고, 채팅별 메시지 수를 영구 카운터로 관리해 시작 시 전체 메시지 집계를 피합니다.
- 긴 채팅을 위로 스크롤할 때 이전 메시지가 갱신되지 않던 문제를 수정했습니다. 기존 40/60개 DOM 상한과 SQL 부분 로딩은 유지합니다.
- 실제 형식과 확장자가 다른 모듈 이미지를 magic bytes로 판별하고, Service Worker 실패 시 무한 대기하지 않도록 자산 fallback과 재시도 경로를 수정했습니다.
- First Message Studio의 다국어, 시나리오, 공유, 이미지 편집 기능과 현재 채팅 저장 슬롯 복원을 추가했습니다.
- Persona Builder lorebook 검색, CBS 분기 보기, 텍스트 테마 대비 보정, 설정 및 컬렉션 패널 크기 조절을 추가했습니다.
- PageFold는 RisuVault의 기존 CJK/이모지 PDF 엔진을 유지하면서 PDF 글자 크기 설정을 추가했습니다.
- 플러그인 SafeElement 이벤트를 요소 범위로 제한하면서 기존 PageFold 보안, 플러그인 수명주기와 SQL 부분 로딩 보호를 유지합니다.

RisuVault가 upstream 0.9.0보다 발전된 영역은 교체하지 않았습니다. 특히 BardWiki 분석 입력의 서버 안전 한도, Haejeok 저장 호환 필드, 모델 프리셋 바인딩과 기존 PageFold 자격 증명 경계는 유지합니다.

iOS 17+ Safari와 설치형 PWA는 지원 사양에 포함되지만 실제 iPhone 기기 검증은 아직 완료되지 않았습니다. Android 실기기 검증은 이 정식 릴리즈로 진행합니다.
