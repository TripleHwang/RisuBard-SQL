# RisuVault 0.3.6

캐릭터나 채팅을 열면 메시지가 하나도 보이지 않던 문제를 고쳤습니다.

## 원인

채팅에 지연 로딩 창을 붙이는 코드가 `Object.defineProperty`를 쓰는데, Svelte 5는 반응형 객체에 그런 속성을 붙이는 것을 거부합니다. 이 코드는 0.3.1부터 있었지만 SQL 저장소를 실제로 쓴 적이 없어 실행될 일이 없었고, 0.3.4에서 마이그레이션이 성공해 SQL 경로에 들어가자 채팅을 열 때마다 실행되어 매번 실패했습니다.

- 실행 시점 표시를 심볼 키로 옮겼습니다. 저장 파일에는 들어가지 않으면서 반응형 객체에서도 동작합니다.
- 메시지 배열을 통째로 바꾸지 않고 필요한 부분만 끼워 넣습니다. 응답이 비어 있거나 실패해도 화면이 비워질 수 없습니다.
- 실패할 수 있는 작업을 모두 먼저 수행하고, 그 뒤에야 채팅을 변경합니다. 중간에 실패해 채팅이 잘린 채로 남는 상태가 없어집니다.

## 함께 고친 것

- 대화 목록에서 밀려난 채팅의 메시지를 사용자가 지운 것으로 보고 데이터베이스에서 삭제하던 문제를 고쳤습니다. 불러오지 않은 것과 삭제된 것은 다릅니다.
- 최근 메시지만 불러온 상태에서 이전 페이지 버튼이 표시되지 않아, 나머지 대화에 접근할 수 없던 문제를 고쳤습니다.
- 메시지를 하나라도 삭제하면 그 뒤로 이전 메시지 불러오기가 계속 실패하던 문제를 고쳤습니다.
- 서버 응답의 위치 정보가 맞지 않을 때 조용히 넘어가던 것을 거부하도록 바꿨습니다.
- 마지막 페이지가 실제로 전체 대화를 담고 있는지 확인한 뒤에만 완전히 불러온 것으로 표시합니다. 내보내기와 백업이 이 표시를 보고 판단합니다.
