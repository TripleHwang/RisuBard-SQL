# RisuVault 0.3.2.6

- 실시간 RisuRealm 카드 스키마와 호환되도록 탐색 데이터 정규화를 보완했습니다.
- 캐릭터 선택은 전체 캐릭터, 선택된 채팅, 범위가 제한된 최근 메시지 페이지가 모두 준비될 때까지 원자적으로 대기합니다. 로딩 실패 시 화면에서 다시 시도할 수 있습니다.
- SQL 요약 메타데이터는 아직 불러오지 않은 본문과 태그를 보존하며, 필요한 선택 채팅만 대상으로 수화(hydration)합니다.
- 같은 chaId를 대상으로 한 SQL 이전 복구는 캐릭터 본문에만 선택적으로 적용하여, 채팅·메시지·설정이 되돌아가지 않도록 했습니다.
- 지연 설정 로더가 채팅 화면을 교체하거나 축소하지 않도록 수정했습니다.
