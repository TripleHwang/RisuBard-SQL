# RisuBard v0.8.12

## 퍼스트 메시지 스튜디오 — 작업 중

> 이 기능은 계속 개발 중이며, 구성 방식과 데이터 형식은 추가 작업 중 변경될 수 있습니다.

### 공유와 Risu 호환 카드

- `공유` 탭을 추가했습니다. 스튜디오 프로젝트를 버전이 포함된 JSON 파일로 내보내거나 다시 가져올 수 있습니다.
- 스튜디오 원본 데이터와 일반 Risu 호환 결과를 같은 캐릭터 카드에 함께 저장합니다. 다른 Risu 클라이언트에서는 일반 퍼스트 메시지, 기본 변수와 트리거로 동작하고, RisuBard에서는 원본을 다시 열어 계속 편집할 수 있습니다.
- 호환 결과를 다시 만들 때 스튜디오가 생성한 변수와 트리거만 교체하여 사용자가 따로 작성한 항목을 보존합니다. V2 캐릭터 카드에도 스튜디오 기본 변수가 포함됩니다.
- 완료 후 출력할 원문 메시지를 스튜디오에서 관리할 수 있게 했으며, 기존 프로젝트에 원문이 비어 있으면 캐릭터에 남아 있는 기존 퍼스트 메시지를 안전하게 가져옵니다.
- 스튜디오를 켜거나 끈 상태 모두에서 생성 코드가 화면에 노출되지 않도록 정리하고, 저장 후 실제 퍼스트 메시지가 항상 설정된 첫 화면에서 시작하도록 수정했습니다.

### 다국어와 편집 화면

- 프로젝트마다 언어의 종류와 개수, 번역 키, 언어 선택 변수와 저장 값을 자유롭게 설정할 수 있습니다. 상단의 편집 언어 드롭다운을 바꾸면 현재 언어의 입력 필드가 즉시 표시됩니다.
- `UI 자동번역`을 추가했습니다. 현재 프로젝트에서 사용자에게 보이는 문자열을 모아 메인 모델에 구조화된 JSON으로 요청하고, 응답의 항목과 식별자를 검증한 뒤 선택한 언어에 일괄 적용합니다. 화면, 선택지, 시나리오와 선택지 프레젠테이션을 함께 처리합니다.
- 언어 설정을 독립된 상단 탭으로 분리하고, 화면 편집 도구와 섞이지 않도록 정리했습니다. 상단 탭과 편집 언어 도구는 스크롤 중에도 유지됩니다.
- 화면 목록의 `새 화면` 버튼을 키우고, 목록에서 화면을 선택하면 즉시 해당 화면 편집기로 돌아가도록 수정했습니다. 선택지 한 줄 개수도 드롭다운에서 고른 값이 계속 표시됩니다.
- 변수 편집기를 한 줄 목록으로 단순화했습니다. 변수 이름, 표시 이름, 기본값, 순서 이동과 삭제를 한 행에서 다룰 수 있으며 각 항목의 용도를 툴팁으로 설명합니다. 사용 빈도가 낮고 화면 선택지와 역할이 겹치던 `선택 가능한 값` 생성 기능은 제거했습니다.
- 창 제목, 설명, 스튜디오 사용 토글의 배치와 스타일을 정리하고 토글의 불필요한 배경을 제거했습니다.

### 조건별 시나리오

- `시나리오` 탭을 추가했습니다. 여러 변수 조건에 따라 서로 다른 완료 메시지를 출력하도록 수식 없이 구성할 수 있습니다.
- 시나리오는 위에서 아래 순서로 평가하며, 한 규칙 안에서 `AND` 조건 그룹과 그룹 내부의 `OR` 조건을 조합할 수 있습니다. `같음`과 `다름` 비교를 지원하고, 여러 규칙이 동시에 맞으면 첫 번째 규칙을 사용합니다.
- 어떤 규칙도 맞지 않을 때 사용할 기본 완료 메시지를 지원하며, 시나리오 메시지는 프로젝트의 다국어 설정과 UI 자동번역에 포함됩니다.

### 선택지 프레젠테이션과 삽화

- 화면별로 `선택지 메인 삽화와 설명`을 켤 수 있습니다. 선택지마다 화자, 설명과 삽화를 지정하면 마우스 호버나 키보드 포커스에 맞춰 메인 프레젠테이션이 즉시 바뀝니다.
- 불러온 삽화는 캐릭터의 추가 에셋으로 저장하고 카드 내부에서는 에셋 이름으로 연결합니다. 프로젝트와 카드를 내보내고 다시 가져와도 연결을 유지합니다.
- 삽화 표시 방식을 원본 비율 유지, 정사각형, 가로형 16:9, 세로형 3:4 중에서 선택할 수 있습니다. 크롭 프레임에서는 이미지를 직접 드래그해 초점 위치를 정하거나 한 번에 중앙으로 되돌릴 수 있습니다.
- 저장한 가로·세로 초점 위치를 실제 미리보기와 Risu 호환 카드에 동일하게 적용합니다. 일반 채팅 이미지 스타일이 스튜디오 삽화의 크기와 크롭 위치를 덮어쓰던 문제도 수정했습니다.
- 삽화 아래에 화자와 설명을 별도 행으로 표시하며, 삽화가 필요 없는 선택지는 이미지 표시만 끌 수 있습니다.

## 세이브 / 불러오기

- 저장 파일을 불러올 때 새 채팅을 추가하지 않고 현재 채팅을 저장 시점의 내용과 Memory Wiki로 교체하도록 수정했습니다. 현재 턴이 저장되지 않은 경우에는 `저장하지 않은 채팅은 사라집니다. 불러올까요?`라는 확인 창을 표시합니다.
