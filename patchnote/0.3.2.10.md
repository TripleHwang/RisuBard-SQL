# RisuVault 0.3.2.10

- 플러그인 목록이 통째로 사라지던 문제를 수정했습니다. 플러그인 목록은 시작 직후 아직 불러오지 않은 상태로 존재하는데, 자동 저장이 이 상태를 "사용자가 전부 삭제함"으로 해석해 데이터베이스에서 삭제하고 있었습니다. 이제 실제로 불러온 뒤에만 저장하며, 아직 불러오지 않은 항목은 저장도 삭제도 하지 않습니다. 플러그인 설정과 저장소는 별도 영역에 있어 이번 문제의 영향을 받지 않았습니다.
- 화면의 모든 버튼이 눌리지 않던 문제를 수정했습니다. 시작 시 설정 불러오기에 실패하고 재시도를 거절하면 로딩 화면이 사라지지 않은 채 남아 클릭을 모두 가로채고 있었습니다. 로딩 화면에 취소 버튼이 생겼고, 시작 실패 화면에서 재시도와 새로고침을 할 수 있습니다.
- 채팅에서 위로 올려 이전 메시지를 불러올 때 "Retry"만 표시되고 더 이상 불러오지 못하던 문제를 수정했습니다. 채팅에 새 메시지가 하나라도 추가되면 이후의 모든 이전 메시지 요청이 실패하고, 새로고침 전까지 복구되지 않았습니다.
- RisuRealm 목록에서 카드 하나를 읽지 못하면 전체 목록이 표시되지 않던 문제를 수정했습니다. 이제 읽을 수 있는 카드는 정상적으로 표시하고, 건너뛴 개수를 함께 안내합니다.
- 페르소나 이미지가 없을 때 대체 이미지가 표시되지 않고 깨진 이미지 아이콘이 그대로 보이던 문제를 수정했습니다.
- 이전 메시지 불러오기 실패와 플러그인 업데이트 실패의 원인이 기록되지 않던 문제를 수정했습니다. 이제 브라우저 콘솔에서 실패 단계와 원인을 확인할 수 있습니다.
