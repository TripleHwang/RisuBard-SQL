# RisuVault 0.3.2.2

- Android WebView나 설치된 바로가기가 `/index.html`로 직접 열릴 때 서버 모드 표시가 빠져 브라우저 SQL을 선택하던 문제를 수정했습니다.
- 이제 `/`와 `/index.html` 모두 동일한 서버 SQL 데이터베이스를 사용하므로, 완료된 `Migrating Local Save to SQL Database...` 단계가 다음 실행에 다시 나타나지 않습니다.
- 최초 SQL 마이그레이션 완료 직후 WAL을 체크포인트하고, 정상 종료 시에도 SQL 체크포인트와 연결 종료를 수행해 모바일 재시작 및 업데이트 시 저장 내구성을 높였습니다.

이 핫픽스는 반복 마이그레이션 문제만 대상으로 하며, 채팅 정규식 및 CSS 표시 성능 개선은 별도 패치에서 진행합니다.
